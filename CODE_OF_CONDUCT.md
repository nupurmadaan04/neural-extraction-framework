# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inclusive environment for everyone.

All contributors and participants are expected to treat others with respect and professionalism.

## Expected Behavior

Participants should:
- Be respectful and considerate
- Provide constructive feedback
- Be collaborative
- Respect different viewpoints
- Help maintain a positive environment

## Unacceptable Behavior

The following behavior is not tolerated:
- Harassment or discrimination
- Offensive comments or personal attacks
- Threats or intimidation
- Publishing private information without permission
- Any behavior that creates an unsafe environment

## Enforcement Responsibilities

Project maintainers are responsible for enforcing the Code of Conduct and ensuring a safe community environment.

## Reporting Violations

If you experience or witness unacceptable behavior, please report it to the project maintainers.

All reports will be handled confidentially.

## Enforcement

Maintainers may take the following actions:
- Warning the contributor
- Removing comments or content
- Temporarily or permanently banning contributors

## Scope

This Code of Conduct applies to all project spaces including:

- GitHub repositories
- Issues and pull requests
- Project discussions
